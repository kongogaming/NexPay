## Repository Description / Tagline Options

Choose one of the following factual, non-exaggerated descriptions for the GitHub repository "About" section:

### Primary Description (Recommended)
> NexPay — an Android offline-first payment app built around USSD, UPI 123PAY, and bank SMS payment confirmation.

### Option 2 (Concise & Focused)
> Offline UPI payments for Android using telecom-native USSD and IVR rails with authoritative bank SMS verification.

### Option 3 (Architecture & Rail Emphasis)
> Android payment client for *99# USSD and UPI 123PAY voice rails with zero internet permission, encrypted local Room persistence, and bank SMS parsing.
